# Solid + TypeScript + Vite

This template includes a counter built with Solid signals, Vite hot module replacement, and Tailwind CSS.

## Development

```bash
pnpm install
pnpm dev
```

Run `pnpm build` to create a production build and `pnpm preview` to serve it locally.

## Checks

```bash
pnpm typecheck
pnpm lint
pnpm stylelint
pnpm fmt:check
```

Oxlint uses Solid-specific rules and Oxfmt sorts Tailwind CSS classes.
